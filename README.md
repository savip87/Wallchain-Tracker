# Wallchain Points Tracker

Трекер баллов Wallchain - веб-приложение для отслеживания баллов пользователей по различным проектам через API Wallchain.

## Описание

Этот сайт позволяет пользователям:
- Ввести свой никнейм
- Получить отчет по баллам для каждого проекта
- Просмотреть общее количество баллов
- Навигировать по страницам данных

## Использование

1. Откройте `index.html` в браузере
2. Введите ваш никнейм в поле поиска
3. Нажмите кнопку "Поиск" или клавишу Enter
4. Просмотрите ваши баллы по проектам

## API

Приложение использует Wallchain API:
```
https://api.wallchain.xyz/voices/points/paginated?pageSize=10&page=1
```

## Файлы проекта

- `index.html` - основная HTML-страница
- `script.js` - JavaScript для работы с API и отображения данных
- `styles.css` - стили для интерфейса

## Особенности

- Поиск пользователя по никнейму
- Отображение общих баллов
- Список баллов по каждому проекту
- Пагинация результатов
- Адаптивный дизайн для мобильных устройств
- Поддержка русского языка
